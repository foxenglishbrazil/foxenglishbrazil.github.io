# Fox English Brazil 🦊💻

> **Tech Communication** — Inglês especializado para desenvolvedores, engenheiros de software e profissionais de tecnologia que buscam carreira internacional, sucesso em reuniões e entrevistas com empresas globais.

Este projeto foi desenvolvido em **Angular 21** standalone, combinando alta performance, design moderno tech (Dark / Glassmorphism / Cyber-Navy), componentes interativos, simulador de nível e integração direta com WhatsApp para agendamento de diagnósticos e cursos.

## 🚀 Tecnologias

- **Angular 21** (Standalone Components, Signals, Control Flow moderno `@if`, `@for`, `@switch`)
- **TypeScript 5.9**
- **Modern CSS** (Design responsivo, variáveis CSS, gradientes tecnológicos, microinterações)
- **WhatsApp Web Integration** (Mensagens estruturadas com protocolo de atendimento automático)

## 📁 Estrutura do Projeto

```
foxenglishbrazil/
├── public/                 # Imagens originais, logo e assets estáticos

```

## 💻 Como Rodar o Projeto

1. Instalar dependências (caso necessário):
```bash
npm install
```

2. Executar o servidor de desenvolvimento:
```bash
npm start
```
Acesse `http://localhost:4208` no seu navegador.

3. Gerar build de produção:
```bash
npm run build
```
